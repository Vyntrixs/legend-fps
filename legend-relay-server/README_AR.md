# LEGEND FPS Relay 2.1

سيرفر WebSocket صغير (Node.js + ws) يدير: الأصدقاء، طلبات الصداقة، حالة الاتصال، ودعوات العوالم.

## التشغيل المحلي
    npm install
    LEGEND_RELAY_TOKEN=سر-اختياري npm start     # المنفذ 8080، المسار /ws

## متغيرات البيئة
- `PORT` (تلقائي على معظم الاستضافات)
- `LEGEND_RELAY_TOKEN` رمز مشترك: من لا يعرفه لا يستطيع الاتصال (موصى به)
- `DATA_FILE` مسار ملف حفظ الحسابات والأصدقاء (افتراضي relay-data.json)

## ما يتحقق منه السيرفر
- الاسم يُربط بأول تثبيت يسجّله (secret خاص بكل تثبيت). هذا **ليس** تحققاً من Mojang: من يعرف الرمز المشترك يمكنه حجز اسم لم يُسجَّل بعد.
- الدعوة تُرسل فقط بين أصدقاء متصلين، والعنوان يجب أن ينتهي بـ `.e4mc.link`.
- حد للمعدل (40 رسالة / 5 ثوانٍ) وحد لحجم الحزمة (4KB).

## ملاحظة الاستضافات المجانية
القرص مؤقت على Render المجاني: يُمسح الملف عند النوم/إعادة التشغيل. المود يحفظ نسخة من أصدقائك ويعيد إرسالها عند الاتصال، ويُستعاد التصادق فقط إذا ادّعى الطرفان بعضهما معاً (يجب أن يتصل الاثنان بعد الاستيقاظ). طلبات الصداقة المعلّقة تضيع ويجب إعادة إرسالها.
