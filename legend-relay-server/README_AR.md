# LEGEND FPS Relay 2.3

خدمة الحسابات والأصدقاء ودعوات العوالم لمود LEGEND FPS على Minecraft Java 1.21.11 / Fabric.

## ما الجديد؟
- تسجيل حساب باسم مستخدم وكلمة مرور (6 أحرف على الأقل).
- تخزين كلمات المرور باستخدام scrypt مع salt عشوائي؛ لا تُحفظ كلمات المرور كنص صريح.
- جلسات دخول عشوائية، مخزّن في قاعدة البيانات بصمة الجلسة فقط، وتنتهي بعد 30 يوماً.
- حفظ الحسابات وقائمة الأصدقاء وطلبات الصداقة في PostgreSQL.
- لا يحتاج اللاعب إلى إدخال LEGEND_RELAY_TOKEN. يبقى هذا الرمز على الخادم فقط.
- يمكن حفظ حتى 3 حسابات على جهاز واحد. يمكن استعمال الحساب نفسه على جهاز آخر بتسجيل الدخول.

## إعداد قاعدة البيانات الدائمة

يحتاج نظام الحسابات إلى PostgreSQL. لا تعتمد على ملف JSON أو قرص Render المؤقت لحفظ الحسابات.

1. أنشئ قاعدة PostgreSQL لدى مزود يدعم PostgreSQL (مثلاً Supabase أو Render PostgreSQL).
2. انسخ **Connection string / URI** الخاص بقاعدة البيانات. لا تنشره ولا ترسله في المحادثات.
3. في Render افتح خدمة `legend-fps-relay` ثم **Environment**.
4. أضف متغيراً باسم `DATABASE_URL` وضع فيه connection string.
5. احفظ التغيير وأعد تشغيل / انشر الخدمة.

عند تشغيل الخادم، ينشئ الجداول المطلوبة تلقائياً:
- `legend_accounts`
- `legend_sessions`
- `legend_social_users`

لا تحتاج إلى تشغيل SQL يدوياً. يجب أن تسمح قاعدة البيانات باتصالات TLS الخارجية. لا تضع `DATABASE_URL` في المود أو مستودع GitHub.

## إعداد Render

الخدمة تستخدم:
- WebSocket: `wss://legend-fps-relay.onrender.com/ws`
- API: `https://legend-fps-relay.onrender.com/api`
- Health: `https://legend-fps-relay.onrender.com/health`

متغيرات البيئة:
- `PORT`: يحدده Render تلقائياً.
- `LEGEND_RELAY_TOKEN`: توافق قديم فقط؛ لا يحتاجه اللاعبون في نسخة الحسابات.
- `DATABASE_URL`: رابط PostgreSQL الخاص بالخادم.
- `MAX_FRIENDS`: الحد الأقصى للأصدقاء (افتراضياً 50).

## استعمال اللاعب

1. ثبّت ملف LEGEND FPS على Fabric مع Minecraft 1.21.11 وJava 21.
2. افتح اللعبة، ثم أنشئ حساباً أو سجّل الدخول من شاشة LEGEND FPS.
3. اختر Friends لإضافة أصدقائك باستخدام اسم حساب LEGEND FPS.
4. افتح عالماً فردياً، ثم Invite to World. يحصل الصديق على دعوة للانضمام عبر عنوان e4mc.
5. يمكن حفظ 3 حسابات كحد أقصى في Account Manager على كل جهاز.

## ملاحظات أمنية وتشغيلية
- حساب LEGEND FPS مستقل عن حساب Microsoft/Mojang، ولا يثبت ملكية اسم Minecraft.
- كلمة المرور لا تُحفظ محلياً. يُحفظ رمز جلسة محلياً حتى لا تضطر إلى تسجيل الدخول كل مرة.
- تسجيل الدخول عبر HTTPS/WSS فقط عند استخدام رابط Render الافتراضي.
- إذا حُذفت قاعدة البيانات أو انتهت جلسة الدخول، قد تحتاج إلى تسجيل الدخول مجدداً.
- الخطة المجانية في Render قد توقف الخدمة عند عدم الاستخدام؛ أول اتصال قد يتأخر أثناء الاستيقاظ.
- هذه الخدمة لا تستضيف عوالم Minecraft. عالم المضيف يبقى على جهازه، وe4mc يوفّر عنوان اتصال مؤقتاً. يجب أن يبقى المضيف داخل العالم حتى يستطيع أصدقاؤه الانضمام.
- لم يتم تأكيد الاتصال بين جهازين وشبكتين مختلفتين بمجرد نجاح البناء؛ يلزم اختبار لعب فعلي بعد ضبط قاعدة البيانات ونشر الخادم.

## التشغيل المحلي للمطورين
