# LEGEND FPS 2.1

Fabric 1.21.11 client mod: red/black menu, cosmetics, performance tools, relay-backed friends, friend requests and world invites with bundled e4mc.

See WORLD_INVITES_AR.md, legend-relay-server/README_AR.md and render.yaml. Build: `./gradlew build` (JDK 21) or push to GitHub and use the `build` workflow.

**Status: not yet built or tested on Minecraft.** The relay server was tested locally (two clients); the Java mod was only syntax-checked.
